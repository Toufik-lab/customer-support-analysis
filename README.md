# Customer Support Performance Analysis

## Project Overview
This project analyzes 500 customer support tickets to evaluate ticket resolution, SLA compliance, customer satisfaction, and agent and team performance.

## Tools Used
- **Microsoft Excel:** Data cleaning and initial analysis
- **PostgreSQL / pgAdmin:** SQL queries, data validation, and analysis
- **Microsoft Power BI:** Interactive dashboard and data visualization

## Key Performance Indicators
- **Total Tickets:** 500
- **Resolved Tickets:** 473
- **Resolution Rate:** 94.6%
- **Average Resolution Time:** 17.65 hours
- **Average Customer Satisfaction:** 3.79 / 5

## Analysis Performed
- Ticket volume by priority and team
- SLA compliance by priority
- Average resolution time by priority
- Agent workload and customer satisfaction
- Monthly ticket trends
- Data quality validation

## Key Findings
- 473 of 500 tickets were resolved, giving a resolution rate of 94.6%.
- Urgent tickets had a lower SLA compliance rate than low-priority tickets.
- Low-priority tickets had the longest average resolution time.
- Average customer satisfaction was 3.79 out of 5.
